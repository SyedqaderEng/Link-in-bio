# Link-in-Bio Demo Themes

Beautiful, professionally designed link-in-bio page templates based on 2024-2025 design trends.

## 🎨 Available Themes

### 1. Glassmorphic Modern
- **Design**: Translucent cards with blur effects, vibrant gradient background
- **Best For**: Tech creators, designers, modern brands
- **Colors**: Purple to Pink gradient
- **Features**: Animated background, floating effects, glassmorphism

### 2. Minimalist Calm
- **Design**: Neutral color palette, maximum whitespace, clean typography
- **Best For**: Wellness, lifestyle, coaches
- **Colors**: Creams, whites, soft grays
- **Features**: Elegant simplicity, subtle animations, refined aesthetics

### 3. Bold & Vibrant
- **Design**: Neon colors, animated gradients, energetic vibe
- **Best For**: Musicians, artists, entertainers
- **Colors**: Neon magenta, cyan, lime on dark background
- **Features**: Glowing effects, animated gradients, high energy

### 4. Nature-Inspired
- **Design**: Earthy tones, organic shapes, calm feel
- **Best For**: Eco brands, artisans, handmade sellers
- **Colors**: Forest green, clay, sand, earth tones
- **Features**: Organic animations, nature-themed, authentic

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the demo selector.

### Build

```bash
npm run build
npm start
```

## 📊 Research

These themes are based on extensive research of:
- Top platforms: Linktree, Beacons, Milkshake, Taplink, Bio.fm
- Current design trends: Glassmorphism, minimalism, bold gradients, nature-inspired
- User preferences and conversion optimization

See `../DESIGN_RESEARCH.md` for full details.

## 🛠️ Tech Stack

- **Framework**: Next.js 16
- **Language**: TypeScript
- **Styling**: CSS-in-JS (inline styles) and CSS
- **Fonts**: Google Fonts (Inter, DM Sans, Space Grotesk, Crimson Pro)

## 📝 Customization

Each theme HTML file can be easily customized:
1. Replace profile image initials with your own
2. Update name, bio, and social links
3. Modify link items and icons
4. Adjust colors in the CSS to match your brand

## 📱 Mobile-First

All themes are designed mobile-first with:
- Touch-friendly buttons (48px+ height)
- Optimized for small screens
- Fast loading times
- Smooth scrolling

## 🎨 Design Principles

1. **Visual Hierarchy**: Clear focus on important elements
2. **Whitespace**: Generous spacing for clarity
3. **Color Psychology**: Colors chosen for target audience
4. **Micro-interactions**: Delightful hover and click effects
5. **Performance**: Optimized for fast loading
