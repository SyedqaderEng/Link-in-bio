# 🎨 LinkBio - Vibrant Modern Theme Demo

Clean, focused demo with only the modern vibrant theme design.

## 📂 Files

### Main Pages:
- **index.html** - Entry point (auto-redirects to dashboard)
- **dashboard-modern.html** - Modern dashboard with visual charts
- **analytics-modern.html** - Advanced analytics with graphs

### Documentation:
- **MODERN-THEME-README.md** - Detailed theme documentation

## 🚀 Quick Start

### Windows:
```bash
# Navigate to folder
cd C:\Projects\Link-in-bio\Link-in-bio\complete-demo\

# Double-click index.html
# OR double-click dashboard-modern.html
```

### Mac/Linux:
```bash
cd complete-demo
open index.html
# OR
open dashboard-modern.html
```

### Local Server (Recommended):
```bash
# Python
python -m http.server 8000

# Node.js
npx http-server -p 8000

# Then open: http://localhost:8000
```
