## 🎨 Design Philosophy

### Color Palette:
- **Primary**: `#FF00FF` (Magenta) → `#00E5FF` (Cyan)
- **Accent**: `#C4FF0E` (Lime Green)
- **Background**: `#0a0a0f` (Deep Black)
- **Surface**: `rgba(255, 255, 255, 0.03)` (Subtle white)
- **Borders**: `rgba(255, 255, 255, 0.1)` (Faint lines)

### Typography:
- **Font**: Inter (Google Fonts)
- **Headers**: 48px, weight 800, gradient text
- **Stats**: 40-48px, weight 800
- **Body**: 14-16px, weight 400-600

### Layout Principles:
- **Asymmetric Bento Grid** - different sized sections
- **Visual Hierarchy** - important data is larger
- **Breathing Room** - generous spacing (20-40px gaps)
- **Responsive** - adapts to all screen sizes
